# PMTCT Longitudinal Data Dashboard

## Overview
This project contains a Streamlit dashboard designed to track Antenatal Care (ANC) attendance and Prevention of Mother-to-Child Transmission (PMTCT) outcomes for HIV-exposed infants. So basically Fai wanted to create a sumarry report for the January 26th Strategic Meeting - Guiding Questions to answer the question that says: Share an analysis of longitudinal data available across the following service delivery points  

PMTCT mother baby pair registered, tested and follow-up milestones ..the document was sent

The analysis was strictly scoped to **20 Optimized Sites** and calculates metrics based exclusively on the "Traceable Mothers" dataset.

## Project Files
* `tues-dashboard.py`: The main Streamlit application containing the dashboard logic, data cleaning, and visualizations.
* `Optimized Sites.xlsx`: An Excel file containing the list of the 20 specific facilities this report focuses on.
* `DATA SET WITH TRACE OF THE MOTHER.csv`: The primary dataset containing linked longitudinal records of HIV-positive mothers and their infants' PMTCT journeys.
* *(Note: The file `DATA SET WITH NO TRACEABLE MOTHERS.csv` was intentionally excluded from this specific analysis per reporting requirements).*

## How to Run the Dashboard
1. Ensure you have Python installed.
2. Open your terminal and install the required libraries:
   `pip install streamlit pandas plotly openpyxl`
3. Navigate to the project folder and run:
   `streamlit run app.py`

## Dashboard Structure & Data Logic
The dashboard is split into two distinct analyses:

### Part 1: ANC Dataset Breakdown (All Time)
This section looks at the entire history of the dataset without any date restrictions.
* **Target Population:** All HIV-positive women who attended ANC at the 20 Optimized Sites.
* **Deduplication Rule:** Because longitudinal data creates a new row for every single clinic visit or test, raw row counts will inflate the numbers. The dashboard explicitly counts **unique IDs** (`child_person_id`) to get the true headcount of exposed infants. *(Example: 58 raw rows in Excel equates to 54 unique babies).*

### Part 2: HIV-Exposed Infant Linkage & Outcomes (Oct 2022 - Sep 2023)
This section isolates a very specific cohort of infants to analyze their 24-month testing outcomes.
* **Date Filter:** Strictly includes infants born between **October 1, 2022, and September 30, 2023**. This is filtered using the `infant_date_of_birth` column.
* **Format Handling:** Dates are parsed dynamically (`format='mixed'`) to prevent Excel formatting inconsistencies (like mixing `dd/mm/yyyy` and `mm/dd/yyyy`) from dropping valid records.
* **Maternal Linkage:** Because this dashboard is built entirely on the Traceable Mothers dataset, **100% of the infants in this cohort are traced**. There are 0 untraced infants in this report.

## Metric Calculation Dictionary
If you need to audit the numbers in the future, here is exactly which columns dictate the metrics:

* **Total HIV-Positive Women:** Count of records where `mother_hiv_test_result` = 'POSITIVE'.
* **Aware/Unaware Prior to Booking:** Evaluates the `mother_hiv_status_at_booking` column.
* **Babies Born / Total Exposed:** Unique count of `child_person_id`.
* **Infants Tested:** Checks if the `infant_hiv_test_result` column is not empty.
* **Infants HIV-Positive:** Filters tested infants where `infant_hiv_test_result` = 'POSITIVE'.
* **Viral Load Suppressed:** Searches `mother_viral_load_result` for indicators like `<30`, `Target Not Detected`, or `TND`.
* **Initiated on ART:** Checks if a valid date exists in the `infant_date_of_art_enrolment` column.
* **Final 24m Outcomes:** Evaluates the text in the `child_hiv_status` column (Positive/Negative/Unknown).

## Notes
* Facility names in the raw data often contain prefixes or spelling variations compared to the `Optimized Sites.xlsx` file (e.g., "ha Avondale Clinic" vs "Avondale Clinic"). The `app.py` script uses a fuzzy string-matching loop to automatically clean and map these together.
